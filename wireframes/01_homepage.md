## Key Features & Interactions

### Video Hero Section
- Full-width background video with sacred geometry visuals
- Overlay text with main value proposition
- Two primary CTAs: "Get the Book" and "Book a Reading"
- Video controls (play/pause, mute/unmute)
- Auto-play with option to pause
- Mobile: Video pauses, shows static image with play button

### Navigation
- Sticky header with logo and main navigation
- Mobile: Hamburger menu
- Clear hierarchy: Home | Shop | Readings | Courses | Blog | About | Contact

### Sacred Geometry Intro
- Three-column layout highlighting key benefits
- Icons representing Ancient Wisdom, Practical Applications, Inner Peace
- Each with descriptive text explaining the value

### Darwin Introduction
- Left-aligned photo, right-aligned text
- Professional yet approachable bio
- CTA to learn more (links to About page)

### Aura Sync Preview
- Visual showcase of geometric patterns
- Clear value proposition and benefits list
- Strong CTA to booking page

### Course Preview
- Three-card layout showing course progression
- Pricing and brief descriptions
- CTA to full courses page

### Testimonials
- Carousel/slider format
- Star ratings and client names
- Social proof to build trust

### Newsletter Signup
- Simple email capture form
- Clear value proposition
- Consent checkbox for GDPR compliance

## Responsive Behavior

### Desktop (1200px+)
- Full multi-column layouts
- Video hero at full height
- Side-by-side content sections

### Tablet (768px - 1199px)
- Two-column layouts where appropriate
- Stacked sections for readability
- Adjusted spacing and typography

### Mobile (< 768px)
- Single-column layout
- Stacked navigation (hamburger menu)
- Hero video becomes static image with play overlay
- Cards stack vertically
- Touch-friendly button sizes (44px minimum)
- Optimized form inputs

## Color Scheme (Crystal Design)
- Primary Purple: `#3a1c71` (deep, spiritual)
- Secondary Teal: `#00c9a7` (calming, expansive)
- Accent Gold: `#ffd700` (enlightenment, prosperity)
- Neutral backgrounds: Light grays and off-whites
- Text: Dark grays for readability

## Typography
- Headings: Playfair Display (elegant, classic)
- Body: Open Sans (clean, readable)
- Hierarchical sizing: H1 (48px) → H6 (14px)
- Body text: 16px base size for readability
